# Login Simple

## Overview
Aplicación web de login simple con HTML, CSS y JavaScript vanilla.

## Goals
- Pantalla de login limpia y responsive
- Validación básica del cliente
- Mensajes de error visuales amigables
- Estado de éxito al iniciar sesión

## Target Users
Usuarios finales que necesiten autenticarse en una demo.

## Tech Stack
- HTML5
- CSS3 (responsive, sin frameworks)
- JavaScript vanilla (ES6+)

## Success Criteria
- Formulario valida campos vacíos
- Muestra errores claros
- Al ingresar credenciales correctas, muestra pantalla de éxito
- Diseño usable en móvil y desktop
