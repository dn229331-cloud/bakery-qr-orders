## Phase Details

### Phase 1: Login Demo UI & Validation

**Goal**: Users can open the app, see a responsive login form, and receive clear visual feedback for empty fields, incorrect credentials, and successful login.

**Depends on**: Nothing (first phase)

**Requirements**: F-01, F-02, F-03, F-04, F-05, NF-01, NF-02, NF-03, NF-04

**Success Criteria** (what must be TRUE):

1. User can open `index.html` in a browser and see a username field, a password field, and a submit button.
2. User sees a clear visual error if either field is left empty and they try to submit.
3. User sees a clear visual/accessibility-friendly error when entering credentials other than `admin` / `123456`.
4. User sees a success state/message after submitting `admin` / `123456`.
5. The layout is usable and visually clean on both mobile and desktop without external frameworks or libraries.

**Plans**: 1 plan
